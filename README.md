# CompAnzLex
Objetivo: Crear un analizador léxico partiendo de lo visto en teoría de la computación (AFD, AFN, Gramatoca, etc.).
En este repositorio se colocará el avance del primer proyecto de Compiladores.

Estructura propuesta:
proyecto/
├── automata.py      ← Teoría: AFN, AFD, conversión, etc. (núcleo)
├── lexer.py         ← Aplicación: AnalizadorLexico.
├── ejemplos.py      ← Demostraciones: Ej1, Ej2, Ej3.
└── main.py          ← Punto de entrada.
