# CompAnzLex
Objective: Create a lexical analyzer based on concepts from the theory of computation (DFA, NFA, Grammars, etc.).
This repository will contain the progress of the first Compilers project.

Proposed structure:
proyecto/
├── automata.py      ← Theory: NFA, DFA, conversion, etc. (core)
├── lexer.py         ← Application: LexicalAnalyzer.
├── ejemplos.py      ← Demonstrations: Ex1, Ex2, Ex3.
└── main.py          ← Entry point.
